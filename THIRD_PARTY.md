# Third-party components

## nerdamer — symbolic algebra (computer algebra system)

- **Version:** 2.0.0
- **Licence:** Apache-2.0
- **Project:** https://github.com/casperw0/nerdamer
- **Bundled at:** `vendor/nerdamer.js` (from `node_modules/nerdamer/dist/bundle.js`)
- **Licence text:** `vendor/nerdamer.LICENSE.txt`

Used for solving equations, differentiating, integrating, limits, limits of
integrals, simplification, expansion and factorisation.

The bundle is vendored rather than loaded from a CDN so the app works offline
and has no third-party runtime dependency. It is loaded lazily, inside a Web
Worker, so it never touches the main thread's critical path.

To update:

```
npm install nerdamer@<version>
cp node_modules/nerdamer/dist/bundle.js       vendor/nerdamer.js
cp node_modules/nerdamer/dist/bundle.js.LICENSE.txt vendor/nerdamer.LICENSE.txt
```

`vendor/nerdamer.js` is a webpack UMD build; it exposes `self.nerdamer`.
